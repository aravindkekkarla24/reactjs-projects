# Authentication Toggle App (React)

This is a simple React application that demonstrates different types of **conditional rendering** using a login/logout system.

The app toggles between Login and Logout states and displays messages accordingly.

---

## Features

- Login & Logout toggle system
- Conditional rendering using:
  - if-else statement
  - Element variable
  - Ternary operator
  - Logical && operator
- Class component with state management

---

## Technologies Used

- React (Class Component)
- JavaScript
- JSX



---

## Concepts Covered

- State management
- Event handling
- Conditional rendering
- JSX syntax



##  Learning Purpose

This project is created for learning React conditional rendering techniques and state handling.
